# 📝 Todo App

A simple and responsive Todo App built using **HTML, CSS, and JavaScript** to manage daily tasks efficiently.

## 🌐 Live Demo

👉 [Try the App](https://yashsharmayy.github.io/Frontend_project/todo%20app/index.html)

- Mark tasks as completed
- Delete tasks
- Data saved using localStorage
- Clean and user-friendly interface
