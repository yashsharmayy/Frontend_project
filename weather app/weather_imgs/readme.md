# 🌦️ Weather App

A modern and responsive Weather App built using **HTML**, **CSS**, and **JavaScript**.  
This application allows users to search for cities and get real-time weather updates with a clean and interactive user interface.

## 🚀 Live Demo

[Weather App Live Demo](https://yashsharmayy.github.io/Frontend_project/weather%20app/weather.html)

---

## 📌 Features

- Real-time weather information
- Search weather by city name
- Temperature display
- Humidity and wind speed details
- Dynamic weather icons
- Responsive design
- Clean and modern UI
- Fast and interactive experience

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Weather API
