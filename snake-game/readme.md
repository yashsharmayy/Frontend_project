# 🐍 Snake Game

A classic Snake Game built using **HTML, CSS, and JavaScript**.  
This project helped me understand core game logic, DOM manipulation, and state management in JavaScript.

---

## 🎮 Features

- Smooth snake movement using keyboard controls
- Collision detection (walls + self)
- Random food generation
- Score tracking system
- High score saved using `localStorage`
- Game over screen with restart button
- Timer to track gameplay duration
- Custom snake head with rotation based on direction

## 🕹️ Controls

| Key   | Action     |
| ----- | ---------- |
| W / ↑ | Move Up    |
| S / ↓ | Move Down  |
| A / ← | Move Left  |
| D / → | Move Right |

## 🚀 How to Run

1. Download or clone the repository
2. Open the project folder
3. Run the `index.html` file in your browser
