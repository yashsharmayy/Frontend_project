## 📌 Project Overview

This project is a professional NGO landing page developed for **She Can Foundation**, a youth-driven organization focused on empowering students through education, skill development, digital initiatives, and community engagement.

The website is designed with a modern orange-red theme inspired by the organization's branding and aims to provide an attractive and user-friendly experience.

---

## ✨ Features

- Responsive Design
- Fixed Navigation Bar
- Modern Hero Section
- About Us Section
- What We Do Section
- Impact Statistics
- Volunteer Call-To-Action
- Hover Effects & Animations
- Smooth Scrolling
- Professional Footer
- Mobile-Friendly Layout

---
